PRISM STUDIO — SITE BUNDLE 1

Files included: homepage, Privacy Policy, Terms & Conditions, stylesheet, site interactions, and the Prism Studio SVG logo.

UPLOAD TO GITHUB
1. Download and unzip this bundle.
2. Open your GitHub repository.
3. Choose Add file → Upload files.
4. Upload the contents of the prism-studio folder (index.html, privacy.html, terms.html, README.txt, and assets/).
5. Commit the uploaded files.

Instagram is provided for general enquiries. The project request form submits orders to the configured Formspree endpoint. Submissions are processed and delivered according to your Formspree settings; this website does not use its own database. The Privacy Policy and Terms & Conditions are drafts and should be reviewed and completed before relying on them.
